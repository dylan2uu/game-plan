# Roadmap

Phase 1 is what's built. **Phase 2 waits until Phase 1 has been used for a full week** (no earlier
than Nov 29, 2026). Then pick at most one item, based on what the night check-ins keep asking for.

## Phase 2 (not built)

- **Daily thinking rep.** One short class problem to answer before any AI, right on the main screen.
  Logged like a task, so it counts toward the streak.
- **Monthly look-back.** The map from a month ago next to the map now, to show what grew.
- **Whatever the night check-in keeps asking for.** Read the last two weeks of "What got in the
  way?" answers in the daily notes, and build only the thing that shows up more than twice.

## Never (on purpose)

Garden, habits, month calendar, chat panel, extra settings. More features made the old versions get
used less.
